# SEMI READY | 반도체 취업·면접 준비

반도체 산업 취업을 준비하는 고졸·초대졸 신입 지원자를 위한 학습 웹앱입니다. 기초 개념부터 8대 공정, 후공정,
장비·설비 CS, 직무와 기업 분석, 면접 답변 작성과 퀴즈·오답노트까지 한곳에서 진행할 수 있습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

Node 18 이상이 필요합니다.

## 구성

```
src/
  data/        학습 콘텐츠 (기초 23주제, 공정 9단계, 후공정 17단계,
               장비·CS 19항목, 직무 12개, 기업 28곳, 면접 질문 37개,
               문제 118개, 용어 75개)
  pages/       라우트별 화면
  components/  레이아웃, 도해(SVG), 차트, 공통 UI
  store/       로컬 스토리지 기반 학습 상태
  lib/         진도 계산, 통합검색 인덱스
  styles/      전역 스타일과 디자인 토큰
```

콘텐츠는 모두 `src/data/`의 타입이 정의된 데이터 파일로 분리되어 있어, 화면 코드를 건드리지 않고 항목을 추가하거나
수정할 수 있습니다. 타입 정의는 `src/data/types.ts`에 있습니다.

## 데이터 저장

로그인과 서버 없이 브라우저 로컬 스토리지(`semi-ready:v1`)에만 저장합니다. 진도, 퀴즈 기록, 오답노트, 면접 답변,
프로필 입력, 즐겨찾기, 지원 기업, 학습 시간이 대상입니다. 설정 화면에서 JSON으로 내보내고 불러올 수 있습니다.

계정별 저장으로 확장하려면 `src/store/store.tsx`의 `AppState`를 서버 스키마로 옮기고, 로드·저장 구간만 API 호출로
교체하면 됩니다.

## 콘텐츠 원칙

- 기업 정보는 사업 영역처럼 비교적 안정적인 내용만 담았습니다. 매출, 투자 규모, 채용 인원, 연봉, 최신 로드맵처럼
  자주 바뀌는 수치는 넣지 않고 공식 출처로 연결합니다. 각 기업 페이지에 정보 확인일을 표시합니다.
- 모든 면접 예시 답변에는 정답이 아니라 참고용이라는 안내를 함께 둡니다.
- 답변 작성 도우미는 입력하지 않은 경력, 성과, 수치, 자격증을 만들어 넣지 않습니다. 비는 자리는 빈칸으로 두고
  무엇을 더 써야 하는지 질문으로 알려 줍니다.
- 모의면접은 생성형 AI와 연결되어 있지 않으며, 화면에 데모 모드임을 명시합니다.
- 직무 비교 수치는 확정된 사실이 아니라 일반적인 경향임을 화면에서 밝힙니다.

## 접근성

- 모든 기능은 키보드로 조작할 수 있고 본문 바로가기 링크를 제공합니다.
- 정답과 오답, 위험 판단은 색만이 아니라 아이콘과 텍스트로 함께 표시합니다.
- 차트는 표 보기 전환을 제공하고 모든 막대에 값 라벨을 붙입니다.
- 필터 결과 수와 저장 결과는 `aria-live`로 알립니다.
- 다크·라이트 모드 모두 대비를 확인했습니다.
